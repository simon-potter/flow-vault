## (3) Tensions & Open Questions

1. **AI look & UI design tradeoff:** `projects/agentic-design/ui-libraries-for-claude-code` says "ban the AI look; use proven libraries." But what about contexts where AI-transparency is a feature (e.g., Invisico showing reasoning)? Is this a tension or separate domains?

2. **When to automate vs. when humans must verify:** Both `research/real-world-process-documentation` (Bolt Lifecycle: verify is 30% of time) and `research/4-person-team-worktree-testing-pattern` (tech lead reviews all PRs) emphasize humans-in-loop. But McKinsey pattern (`concepts/ai-engineering/enterprise-ai-transformation-patterns`) suggests night-shift agents + async validation. How do these scale together?

3. **Test debt remains unresolved:** `research/real-world-process-documentation` explicitly flags test debt as a common failure mode ("tests pass but nothing's tested") but doesn't provide a clear fix beyond "humans write acceptance tests." Need to audit how our projects handle this.

4. **Writing workflow assumes Hermes always available:** `projects/writing-workflow/*` centers Hermes for research, editing, WordPress publishing. What's the fallback if Hermes is down or slow?
