## 5 Core Ideas

### 1. The Internet: Open (1990s) → Closed (2010s) → Open Again (now)

**Lost:** Open chat (IRC), APIs everywhere, file ownership, customizable sites, creative freedom  
**Gained:** Closed platforms, licensing, gatekeeping, rent extraction (Adobe's $200 termination fee)

**Term:** "Enshittification."

### 2. AI Agents Reverse Consolidation

Prompt: "Build me Photoshop. Make it MCP and CLI compatible." → 24 hours → Functional Photoshop (10x faster, 60% parity).

**What they cloned:**
- Photoshop, InDesign, Premiere, Figma, Microsoft Office, Google Docs, CAD, Flash, DAWs
- Plus 300+ community apps

**Cost:** Fraction of Adobe R&D. **Model:** 100% open source.

### 3. Artists Become Builders

Advisors said: "Artists don't use open source."  
Reality: Micro-drama studios ($30-50k/month) used agents to build custom interfaces from ArtCraft APIs for their exact workflow.

**Lesson:** Open + agents turns consumers → builders.

### 4. Agents Can Drive Everything (Except Schema/API Design)

Works best on: Desktop apps, games, immutable features (full confidence, no human-in-the-loop).  
Proof: 40 machines rebuilding Unreal Engine in Rust autonomously.

### 5. AutoCraft: Autonomous Software Factory

Open source (launching soon):
- Ingests issues
- Auto-triages
- Runs agentic dev autonomously
- Posts training data from decisions

## SaaS Business Model: What Changes?

### **What Dies**

- Subscription software ($20-80/month) → Free open source, better
- Licensing (per-seat) → Self-hosted, owned
- Cloud lock-in → Desktop-first + optional server
- Feature gatekeeping (Pro/Free tiers) → One version, customizable

**TAM at risk:** $500B+ (Adobe, Microsoft licensing, Autodesk, Figma, Jetbrains, Atlassian, enterprise software)

### **What Replaces It: 4 Models**

#### Model 1: Infrastructure/Hosting
You give software away. You sell where to run it.
- "Run Figma-alternative on our servers (10,000 seats)."
- Pricing: Per-compute + per-storage (not per-feature)

#### Model 2: Customization/Integration  
You sell services.
- "Your micro-drama studio needs a custom interface? Agents build it."
- Revenue: Professional services, consulting

#### Model 3: AI Post-Training
Every open app generates training data (decisions, workflows).
- "Premium agents that understand your domain deeply."
- Revenue: Better models, better automation

#### Model 4: Enterprise Governance
You sell confidence + compliance.
- "Audit it, secure it, make it SOC2/HIPAA."
- Revenue: Support SLAs, compliance, indemnification

**Winners:**

**Losers:**

- Enterprise software (Salesforce, SAP)
- Feature-based subscription businesses

## The Paradox

Open (1990s) → Closed platforms (2010s) → Open source again (2020s+)

But economics shift:
- Software licensing → Infrastructure + services + models + customization
- "Buy this app" → "Generate this app when you need it"
- Gatekeeping → Competing on agent quality
