## Implementation Patterns

### Personal Agent vs Custom Agent
- **Personal Agent:** Interactive chat, credit-efficient, best for iterative work
- **Custom Agent:** Team-wide, scheduled, specific jobs, higher cost

### Self-Improving Knowledge Base Loop
1. Review KB for gaps
2. Research reputable sources
3. Propose new entries
4. Add to KB
5. Iterate next cycle

### Ingestion Workflow
1. Get chapter list as structure
2. Extract content atomically
3. Normalize into KB schema
4. Add confidence levels
5. Link across sources
