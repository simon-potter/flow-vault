# Hermes Multi-Project Marketing Automation Masterplan

**Purpose:** A living framework for scaling projects using **Hermes Agent as the orchestration layer** for multi-channel marketing automation. This represents current best practices distilled from 8+ successful implementations.

**Last Updated:** 2026-06-13 (version 1.0-stable)  
**Foundation:** [[projects/marketing-for-nerds]] research + 3 new case studies  
**Maintenance:** Evolves quarterly with new implementations

## Part 1: The Vision (Why This Works)

### The Core Problem We're Solving

**Traditional marketing for multi-project businesses:**
- Each project needs its own marketing (duplicated effort)
- Manual work across 8-15 platforms is unsustainable
- Content creation is manual + slow → revenue ceiling exists
- Sales follow-up is inconsistent → leads die
- No learning loop → same mistakes repeat

**The Hermes Solution:**
- **One agent orchestrates all projects** (saves 400+ hours/year per project)
- **Multi-platform automation** (15 platforms from single workflow)
- **Compound learning** (memory grows → output improves each week)
- **Sales automation** (85% of pipeline can be automated)
- **Content leverage** (one idea becomes 20 formats across all projects)

### The Economics That Make This Real

**Cost structure (per project):**
- Hermes setup: **1-2 hours** (one time)
- Core automation: **$300-500/month** (API costs only)
- Hermes time investment: **4-5 hours/week** (monitoring + optimization)

**Revenue impact:**
- Content output: **5-10x faster** than manual
- Lead qualification: **85% automated** (removes bottleneck)
- Customer acquisition cost: **30-50% reduction** (systematic outreach)
- Sales cycle time: **2-3x faster** (automated follow-up)
- Revenue per team member: **3-4x higher** (leveraged by agent)

**ROI:** 1-2 days of employee salary covers a month of tool costs. First project pays for itself in 3-4 weeks of operation.

## Part 2: The Technical Architecture

### Layer 1: The Orchestrator (Hermes Agent)

**Why Hermes is the control layer:**
- ✅ Unified interface (no context switching)
- ✅ Built-in memory system (learns your brand)
- ✅ Security by default (prompt injection protection)
- ✅ Reliability (doesn't break like fragile multi-tool setups)
- ✅ Skill stacking (add capabilities incrementally)

**Hermes does NOT do:**
- ✗ Code generation (delegate to Claude Code)
- ✗ Heavy tool calling (delegate to OpenClaw)
- ✗ Browser automation (delegate to Firecrawl/BrowserBase)

**Hermes DOES own:**
- ✓ Central decision-making
- ✓ Workflow orchestration
- ✓ Memory/context management
- ✓ Multi-project coordination
- ✓ Result synthesis and reporting

### Layer 2: Specialist Tools (The Supporting Cast)

#### Content Generation
- **for blogs/long-form:** Claude Opus via Hermes
- **for images:** ComfyUI (local) or image gen API
- **for video:** Future: Runway/CapCut (external API)
- **for social captions:** Claude (platform-specific variations)

#### Code & Complex Logic
- **Claude Code** — Planning, architecture, complex workflows
- **Codex** — Execution, tool calling, function generation
- **OpenClaw** — Heavy multi-API orchestration (when needed)

#### Data Gathering
- **Firecrawl API** — Web scraping, competitor research
- **BrowserBase** — Reliable browser instance management
- **Cameo Fox** — Anti-bot evasion (aggressive sites)

#### Platform APIs
- **Genviral** — Multi-platform social distribution (8+ platforms)
- **Individual platform APIs** — Instagram, X, LinkedIn, TikTok, YouTube, etc.
- **Email/CRM** — HubSpot, Mautic, Pipedrive webhooks
- **Analytics** — Google Search Console, native platform analytics

### Layer 3: Data Layer (The Memory System)

**What Hermes remembers:**
- Brand voice + positioning (improves with each use)
- Past campaign performance (what worked, what didn't)
- Client details + preferences (for sales automation)
- Project-specific context (goals, audiences, differentiation)
- Competitor + market intelligence (refreshed weekly)

**How it works:**
- **Day 1:** Raw facts stored (you tell agent key info)
- **Week 1:** Pattern recognition (agent identifies what converts)
- **Month 1:** Memory rivals junior employee (predicts next best action)
- **Quarter 1:** Agent suggests campaigns agent would never think of

**Critical:** Memory is the multiplier. Each project's learning benefits all other projects.

### Layer 4: Skill Stacking (Progressive Capability)

**Implementation timeline (start here):**

| Week | Focus | Setup | Benefit |
|------|-------|-------|---------|
| Week 1 | Content generation | 1-2h | Posts schedule themselves |
| Week 2 | + Social scheduling | +30m | 8 platforms, one workflow |
| Week 3 | + Comment monitoring | +30m | Leads notified auto-reply |
| Week 4 | + Email sequences | +1h | Follow-up becomes automatic |
| Week 5 | + Lead qualification | +1h | Sales team gets pre-screened leads |
| Week 6 | + Analytics reporting | +30m | Insights fed back into system |

**Key principle:** Each new skill multiplies the power of all previous skills. Cumulative effect is exponential, not linear.

## Part 3: The Campaigns (Practical Implementation)

### Campaign Type 1: The Content Generation Engine

**What it does:**
- One prompt → 20+ pieces of content (email, social, blog, LinkedIn, TikTok scripts)
- Multi-format output (text, images, video scripts)
- Platform-optimized variations (LinkedIn voice ≠ TikTok voice)
- SEO-aware by default (informed by brain, not generic)

**Setup (2 hours):**
1. Feed agent 3-5 of your best past campaigns (what converts)
2. Define tone + brand voice (1 page doc)
3. Set content pillars (what your project is known for)
4. Connect image gen API (ComfyUI or Replicate)
5. Test with one campaign → iterate until you like output

**Monthly output:** 40-80 pieces of original content (from 4-5 hours of setup/refinement)

**Success metric:** Click-through rate on social posts. Target: 2-3x above platform average.

---

### Campaign Type 2: The Lead Generation + Qualification Engine

**What it does:**
1. Monitors social comments + DMs across all platforms
2. AI identifies warm leads (intent signals)
3. Auto-replies with value + qualification question
4. Sends WhatsApp/SMS with deeper question
5. Surfaces only qualified leads to sales team

**Setup (3-4 hours):**
1. Define "warm lead" signals (what to look for)
2. Write 3-4 auto-reply templates (platform-specific)
3. Set up WhatsApp/SMS integration (need tokens)
4. Define qualification criteria (budget, timeline, pain point match)
5. Connect output to sales CRM or Slack channel

**Workflow:**
```
Social media comment/DM
    ↓
Hermes reads via API monitor
    ↓
Is this a warm lead? (intent signals)
    ↓
Auto-reply with value + question
    ↓
Lead replies on social/WhatsApp
    ↓
Agent qualifies: budget/timeline/fit
    ↓
If qualified → slot into sales sequence
If not qualified → nurture loop
```

**Monthly output:** 30-50 qualified leads (from 2 hours of monitoring)

**Success metric:** % of leads that convert to paying customers. Target: 15-25%.

---

### Campaign Type 3: The Email Sequence Engine

**What it does:**
- Generates personalized email sequences (not templates)
- Triggered by specific behavior (download, demo request, cart abandon)
- Adapts tone based on recipient signals (warm vs cold)
- A/B tests variants automatically

**Setup (2-3 hours):**
1. Define 4-5 trigger events (what starts the sequence)
2. Map out desired outcomes per sequence
3. Feed agent past high-converting emails (learn from)
4. Connect email platform API (HubSpot, ConvertKit, Mautic)
5. Set up A/B testing (variant A/B rotation)

**Workflow (example - demo request):**
```
User requests demo
    ↓
Hermes triggers "demo_sequence_day_0"
    ↓
Send intro email (personalized)
    ↓
Day 3: Soft nudge email
    ↓
Day 7: Case study email
    ↓
Day 10: Social proof email
    ↓
Day 14: Urgency/scarcity (if not booked)
    ↓
Day 20: Final win-back email
```

**Monthly throughput:** 200-500 emails sent (from 1 hour of setup). Cost: basically $0 (your API calls).

**Success metric:** Click rate (target: 25%+), reply rate (target: 5%+), conversion rate (target: 2-5%).

---

### Campaign Type 4: The Multi-Platform Content Syndication Engine

**The "write once, deploy everywhere" workflow:**

**What it does:**
1. You write/create ONE piece of content (blog post, whitepaper, video)
2. Hermes extracts 15-20 variations (titles, angles, formats)
3. Deploys to ALL platforms simultaneously (optimized per platform)
4. Monitors engagement across all channels
5. Feeds insights back → next piece gets smarter

**Platform coverage:**
- Social: Instagram, X/Twitter, Facebook, LinkedIn, TikTok, Threads, Bluesky, Pinterest
- Email: Newsletter, lead nurture sequences
- Blog: Multiple sites (if applicable)
- Search: Optimized for featured snippets
- Video: YouTube, Shorts scripts
- Community: Discord, Slack, forums

**Setup (1-2 hours):**
1. Connect Genviral (handles 8+ social platforms)
2. Set up image variations (one image → 4-5 crop variations per platform)
3. Define posting schedule (when + frequency per platform)
4. Create platform-specific brand guidelines (tone, hashtags, format)
5. Enable analytics aggregation (consolidated reporting)

**Example workflow:**
```
Blog post published
    ↓
Hermes extracts 3 core insights
    ↓
Generates variations:
  - 8 social media posts (platform-optimized)
  - 3 email subject lines
  - 2 LinkedIn articles
  - 1 TikTok script
    ↓
Creates/sources images for each
    ↓
Schedules across all platforms
    ↓
Monitors engagement for 24 hours
    ↓
Feeds learnings → next piece gets posted smarter
```

**Monthly output:** 1 solid piece of content becomes 40+ deployments (reach: 50k-500k impressions depending on audience)

**Success metric:** Total reach + engagement rate. Target: 2-5% engagement rate across channels.

### Campaign Type 5: The Sales Automation Engine

**The full flow: Lead → Qualified → Closed (automated)**

**What it handles:**
1. Inbound lead capture (website form, social, email)
2. Instant lead response (15-min response beats everyone)
3. Qualification via conversation (Hermes asks the right questions)
4. Proposal generation (auto-templated, personalized)
5. Follow-up sequences (touches increase with time)
6. Win/loss analysis (learn why deals close/fail)

**Setup (4-6 hours):**
1. Map your sales process (current state)
2. Define qualification criteria (who is a good fit)
3. Connect CRM (HubSpot, Pipedrive, Salesforce, Notion)
4. Write sales email templates (Hermes learns to personalize)
5. Configure SMS/WhatsApp integration (for hot leads)
6. Set up deal pipeline automation (trigger sequences at each stage)

**The 85% automation breakdown:**
- ✅ Lead capture + initial response → 100% automated
- ✅ Qualification questions → 90% automated (agent asks, learns answers)
- ✅ Proposal generation → 75% automated (templated + personalized)
- ✅ Follow-up sequencing → 100% automated (time-triggered)
- ✅ Deal analysis → 100% automated (why did it close? learn it)
- ❌ Actual conversation + negotiation → 20% automated (human owns this)

**Timeline for typical SaaS lead:**
```
Day 0 (Lead arrives):
  - Auto-response within 15 min
  - Schedule calendar slot (auto-suggested time)

Day 0-1:
  - Qualification call (agent monitors, surfaces questions)
  - Same day follow-up with personalized summary

Day 2:
  - Proposal sent (auto-generated, personalized)

Day 3-7:
  - 2-3 automated touch points (email, WhatsApp)
  - Monitor engagement signals

Day 7+:
  - If engaging: escalate to sales team
  - If ghost: nurture campaign kicks in
```

**Success metric:** Sales cycle time (target: 50% reduction), close rate (target: 25-40%), pipeline velocity.

## Part 6: Risk Mitigation & Pitfalls

### Common Failure Mode 1: "Agent is a Content Machine, Not a Revenue Machine"

**The mistake:** Setting up content automation, expecting revenue to follow.

**Why it fails:** Content without sales follow-up is just noise. Hermes is an automation tool, not a sales tool by itself.

**The fix:**
- Content automation → lead generation automation → sales automation (sequential)
- Don't skip the middle steps
- Measure at each layer: content reach → lead quality → revenue/customer

**Timeline:** Expect 6-8 weeks before seeing revenue impact. Content is week 1. Sales automation is week 4+.

---

### Common Failure Mode 2: "Set It and Forget It"

**The mistake:** Configure automation, then not touch it for 3 months.

**Why it fails:**
- Agent memory goes stale (learns from old data)
- Market changes (what worked in Jan doesn't work in Apr)
- Audiences evolve (messaging gets tired)
- Agent can't improve without feedback

**The fix:**
- Weekly check-in: 30 min of monitoring + optimization
- Monthly deep dive: 2 hours of data review + prompt updates
- Quarterly refresh: update brand voice + market positioning
- This is NOT a fire-and-forget system

**Time investment:** 4-5 hours/week, results in 20-40 hours of value created.

---

### Common Failure Mode 3: "Automation Without Strategy"

**The mistake:** Automating bad sales process = faster failure.

**Why it fails:** If your sales conversation doesn't solve the customer's problem, automating it just loses leads faster.

**The fix:** Read + implement [[projects/marketing-for-nerds/sales-fundamentals]].
- Master the "Reality Gap" method (customer current state → desired state → you as bridge)
- 70% of conversation should be about THEM, not you
- Then automate the good conversation

**Critical:** If your *manual* sales process has 20% close rate, your automated process will too. Automation multiplies, it doesn't fix.

---

### Common Failure Mode 4: "Trying to Automate Everything at Once"

**The mistake:** Connecting all 15 platforms + email + SMS + sales automation on Day 1.

**Why it fails:**
- Too many moving parts to debug
- Agent gets confused (conflicting instructions)
- Overwhelming setup time (2 weeks instead of 1)
- High failure rate = lack of confidence

**The fix:** Skill stacking methodology (see Part 2, Layer 4).
- Week 1: One platform (Instagram or X)
- Week 2: Add second platform
- Week 3: Add email
- And so on...

**Each layer works → confidence builds → complexity can handle it.**

---

### Common Failure Mode 5: "Memory Pollution"

**The mistake:** Agent remembers old, bad data → gives worse recommendations over time.

**Why it fails:**
- "We tried TikTok in Jan, got no leads, so TikTok doesn't work"
- Agent repeats that assumption forever
- Actually: the problem was poor content or audience mismatch, not the platform

**The fix:** Monthly memory audit.
- Review what agent "knows" about your brand
- Correct false assumptions
- Remove outdated patterns
- Add new learning from current data

**Process:** 1 hour/month prevents 6 months of bad recommendations.

## Part 8: The Operating Model (How to Scale)

### Month 1-3: Solo Operator Model

**You are:**
- Chief strategist (decide what to automate)
- Content director (guide Hermes on brand)
- Performance analyst (weekly metrics review)

**Time:** 5-7 hours/week (setup) → 4-5 hours/week (ongoing)

**Output:** 1-2 projects automated, 40-80 pieces of content/month, 10-20 qualified leads/month

---

### Month 4-6: Delegation Model

**As you add projects, hire a "Hermes Manager"** (part-time)

**This person owns:**
- Weekly monitoring of all projects
- Prompt optimization (ask for marginal improvements)
- CRM/lead qualification workflow
- Weekly reporting to you

**You focus on:**
- Strategic decisions (market shifts, new projects)
- Sales conversations (close the deals)
- Brand evolution (quarterly updates)

**Time for you:** 3 hours/week (strategy + sales)  
**Time for manager:** 15-20 hours/week (execution)

**Output:** 5-8 projects automated, 200-300 pieces of content/month, 50-100 qualified leads/month

---

### Month 7-12: Team Model

**Hire a small marketing ops team:**
- **Hermes Manager** (1 FTE) — agents, optimization
- **Content Creator** (1 part-time) — strategy, brand direction
- **Sales Ops** (0.5 FTE) — CRM, lead qualification workflows

**You focus on:**
- Strategic positioning (what to double down on)
- Top client meetings (high-value only)
- Market expansion (new projects, new channels)

**Time for you:** 5-7 hours/week (strategy + board-level decisions)  
**Time for team:** 3 FTE total

**Output:** 15+ projects or 1 mega-project with 1000+ pieces of content/month, 300+ qualified leads/month, $500k+ ARR generated

## Quick Reference: Which Campaign to Start With?

**If you have:** Decent following, bad conversion → Start with **Campaign Type 1** (content)  
**If you have:** Traffic, but loose lead quality → Start with **Campaign Type 2** (qualification)  
**If you have:** Leads, but slow follow-up → Start with **Campaign Type 3** (email)  
**If you have:** One success, want 5 more → Start with **Campaign Type 4** (syndication)  
**If you have:** Sales team, clogged pipeline → Start with **Campaign Type 5** (sales automation)  

**Our recommendation:** Start with **Campaign Type 1 + 2** (content + lead gen). These create the flywheel. Then add Type 5 (sales) once you have 20+/month leads. Type 3 and 4 are optimizations after.
