## Summary

Mihail Eric from Stanford discusses how AI will reshape the software engineering job market in the next 5 years. He identifies three job categories that will disappear (QA engineers, entry-level consultants, entry-level data analysts) due to automation by coding agents, and three emerging roles that will explode: forward-deployed engineers, AI platform engineers, and AI feature engineers. The key theme: hands-on keyboard work that can be described in a ticket is replaceable; high-judgment, cross-disciplinary roles are not.

Computer science unemployment has reached 6.1%, the seventh-highest among college degrees, driven by the rise of coding agents and the resulting "up-leveling" of expectations. Juniors can still survive by becoming interdisciplinary (combining coding with design, PM, customer success).

## Key Insights & Highlights

**Job Market Reality (2026):**
- CS unemployment: 6.1% (seventh-highest among college degrees)
- Expectation gap widening: juniors now expected to ramp at senior-engineer speed
- Companies choosing senior candidates over juniors in same-role comparisons (myopic short-term thinking)

**Jobs That Will Disappear:**
1. **QA Engineers** — simple testing, button-clicking, ticket-based triaging → easy to outsource to agents
2. **Entry-Level Consultants** — manual labor on pre-scoped projects → coding agents replace them
3. **Entry-Level Data Analysts** — rudimentary data exploration → no longer needed

**Jobs That Will EXPLODE:**
1. **Forward-Deployed Engineer**
   - On-site with customers; translates customer needs into software
   - Interdisciplinary: PMing + support + engineering + customer voice
   - Decomposition & translation skill essential
   - Example: "Customer says button doesn't work" → "They need an entirely new feature"

2. **AI Platform Engineer**
   - Builds foundations for agentic systems (inference, evaluation, data orchestration)
   - Decisions: Brain Trust vs. Judgment Labs, Fireworks vs. Modal for inference
   - Manages infrastructure layer upon which agents are built
   - "AI IT department"

3. **AI Feature Engineer**
   - Builds bespoke agentic features on top of platform infrastructure
   - Example: insurance agent that summarizes PDFs grounded in domain-specific knowledge
   - Vertical/domain-specific

**Why Juniors Can Still Survive:**
- Juniors have high learning velocity and adaptability
- Openness to new tools (high slope, even if low Y-intercept)
- Crucial for startups/small companies that value speed & adaptability
- BUT only if they're interdisciplinary and can merge multiple disciplines

**How to Become Top 1% (Get Ahead of 99% of Engineers):**

1. **Piecemeal Problem Breaking**
   - Decompose complex tasks into subtasks with clear dependencies
   - Assign to agents, not try to run everything at once

2. **Context Switching Among Agents**
   - Act as "scrum master of the team of agents"
   - Know which agent is stuck, when to introduce clarity, when to start a new agent
   - Maintain context across multiple parallel agentic workstreams
   - Psychological skill: managing the "most eager interns on the planet"

3. **Agent-Friendly Codebases**
   - Strong test coverage
   - Strong build system
   - House built before agents enter to add rooms
   - Enables confidence in multi-agent execution

**Interdisciplinary Edge:**
- Example: UX/UI designer + coding agent = sketch → full Vercel app
- Example: Hardware systems + coding agent = domain-specific solutions
- Combining design, PM, customer success, coding creates unique, defensible value

**College Still Worth It?**
- If you're just learning Python/JavaScript and expecting a job: no
- If you're learning meta-skills (approaching open-ended problems, scopping, talking to people, defining requirements): yes
- College is a unique opportunity to dial in on soft skills & systems thinking
