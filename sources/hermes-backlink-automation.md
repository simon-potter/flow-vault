## Summary

A tutorial on using Hermes Agent to automate the entire link-building outreach workflow. The core idea: set up an AI agent with an email inbox, give it a task (find target websites, write personalized emails, request backlinks, follow up), and let it run on autopilot daily. The presenter demonstrates a "self-writing inbox" architecture—five layers that turn a standard email account into a fully autonomous outreach machine. Key value proposition: eliminates manual cold-email work that typically requires hours spent in an inbox.

## Key Segments & Topics

### 1. **The SEO Fundamentals** (Opens ~00:22–01:00)
- More backlinks → more referring domains → more traffic
- Building backlinks manually is slow, boring, and leads to abandonment
- Automation via AI agent solves this

### 2. **Core Concept: The Self-Writing Inbox** (01:00–02:30)
- Give Hermes Agent its own email inbox (not your personal one)
- Agent reads emails, sorts them, understands priorities, writes replies, sends outreach
- Once configured, runs autonomously with no input

### 3. **Link-Building Anatomy** (02:30–04:30)
- Link building = cold email, but personalized
- Steps: find good sites → write email → ask for backlink → reach out → follow up
- **Each step can be delegated to the AI agent**

### 4. **Live Demo: AI Profit Boardroom Example** (04:30–07:00)
- Goal: build backlinks to a free guide inside their community
- Hermes is given three pieces of information:
  1. The website and target page
  2. Task: reach out to 5 relevant websites per day
  3. Instructions: keep emails short, personalized, schedule follow-ups
- Agent finds prospects or uses a pre-supplied list and executes daily

### 5. **Simple Prompt Template** (07:00–07:30)
```
"You're my link-building outreach team for this website. 
Email these five blogs asking for a backlink."
```
Agent then writes and sends personalized emails automatically.

### 6. **The Five-Layer Self-Writing Inbox Architecture** (07:30–end)
1. **Dedicated inbox**: Create a private email address for the agent (not your personal inbox)
2. **Google Service Account**: Generate credentials, plug into Hermes
3. **Hermes setup**: Tell Hermes the email address and service account details; it connects automatically

## Key Takeaways

1. **Automation viability**: The entire link-building pipeline (prospecting, emailing, follow-ups) is actionable for an AI agent with email and web access.
2. **Agent OS context**: Hermes Agent runs on Agent OS (a dashboard where multiple agents share memory and context), enabling coordination.
3. **Minimal setup**: Three simple pieces of information + a Google service account credential = autonomous outreach.
4. **Scheduled recurrence**: Tasks can be scheduled (e.g., "reach out to 5 sites per day") and run in the background without intervention.
